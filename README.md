# HR Attrition Prediction & Analytics

An end-to-end Data Science project to predict employee attrition and provide actionable insights for HR teams.

### 🤖 Model Performance
- **Algorithm Used:** XGBoost Classifier
- **Accuracy:** 90% on Test Data
- **Dataset:** IBM HR Analytics Dataset

### ✨ Key Features
- Real-time Attrition Prediction with Streamlit App
- Power BI Dashboard for Management Insights
- Fully Dockerized for Easy Deployment

### 🛠️ Tech Stack
Python | Pandas | XGBoost | Scikit-learn | Streamlit | Power BI | Docker

### 📁 Project Structure
- `app.py` - Main Streamlit App
- `WA_Fn-UseC_-HR-Employee-Attrition.csv` - Dataset
- `attrition_model.pkl` - Trained Model
- `HR Attrition Dashboard.pbix` - Power BI File

### ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
